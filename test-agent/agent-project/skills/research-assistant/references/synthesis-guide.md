# Synthesis Guide

## Structuring a Research Report

### Executive Summary
Write 3-5 sentences that answer the user's core question. A reader who only
reads this section should walk away informed.

### Organizing Key Findings
- Group related findings under thematic headings.
- Lead each group with the strongest / most relevant finding.
- Use bullet points for scannability.

### Handling Conflicting Sources
When sources disagree:
1. State the disagreement explicitly.
2. Note the credibility/recency of each source.
3. Present the most well-supported position first.
4. Flag uncertainty with hedging language ("evidence suggests", "according to").

### Citation Format
Use inline numbered references: "AI safety spending increased 40% [1]."
List full URLs in a Sources section at the end.
