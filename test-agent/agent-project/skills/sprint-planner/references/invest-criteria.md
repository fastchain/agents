# INVEST Criteria for User Stories

Score each criterion 0-2 (0 = not met, 1 = partially met, 2 = fully met).
Maximum score: 12.

## I — Independent
The story can be developed and delivered without depending on other stories
in the same sprint. Score 0 if it's tightly coupled.

## N — Negotiable
The story describes *what* and *why*, not *how*. Implementation details are
left to the team. Score 0 if it prescribes a specific technical solution.

## V — Valuable
The story delivers clear value to the user or business. Score 0 if it's
purely technical with no user-facing benefit.

## E — Estimable
The team can reasonably estimate the effort. Score 0 if the scope is too
vague or requires a spike first.

## S — Small
The story fits within a single sprint. Score 0 if it's an epic that needs
decomposition.

## T — Testable
There are clear acceptance criteria that can be verified. Score 0 if
"done" is subjective or undefined.
